# run study

> 같이 있진 않지만, 같이 있는 느낌

친구들끼리 대화 없이 존재감만 공유하는 macOS 메뉴 막대 앱.

> **현재 상태 — UI 프로토타입**
> `.env` 없이 받으면 **목 데이터**로 돌아갑니다. 화면은 전부 동작하지만
> 실시간 공유는 Supabase 를 연결해야 켜집니다([아래](#supabase-연결)).
> Tauri(트레이·집중 모드) 쪽은 아직 실기기 검증 전입니다.

**macOS · Windows 둘 다 빌드됩니다.** 차이는 알림 끄기(집중 모드)뿐 —
macOS 만 지원하고, Windows 에서는 해당 설정이 아예 안 보입니다.
설치 파일은 [GitHub Actions 로 양쪽을 한 번에](#친구에게-줄-설치-파일-만들기) 뽑습니다.

## 실행

```bash
npm install
npm run tauri:dev     # 개발 (맥에서만)
npm run dev           # 브라우저에서 UI만 확인 (트레이 없음)
```

### `tauri dev` 가 `cargo metadata ... No such file or directory` 로 죽는다면

Rust 가 안 깔린 겁니다. Tauri 는 Rust 로 빌드돼요.

```bash
xcode-select --install                                              # 이미 있으면 건너뜀
curl --proto '=https' --tlsv1.2 -sSf https://sh.rustup.rs | sh      # 기본값(1) 선택
source "$HOME/.cargo/env"                                           # 또는 터미널 새로 열기
cargo --version                                                     # 확인
npm run tauri:dev                                                   # 첫 빌드는 5~10분
```

내 컴퓨터용으로만 빌드:

```bash
npm run tauri:build   # macOS → .app/.dmg,  Windows → -setup.exe/.msi
```

## 친구에게 줄 설치 파일 만들기

**맥에서 윈도우 exe 를, 윈도우에서 맥 dmg 를 만들 수 없습니다.**
그래서 `.github/workflows/build.yml` 이 두 OS 러너에서 각각 빌드합니다.

### 1. Secret 등록 (한 번만)

레포 **Settings → Secrets and variables → Actions → New repository secret**

| 이름 | 값 |
|---|---|
| `VITE_SUPABASE_URL` | `https://xxxxx.supabase.co` |
| `VITE_SUPABASE_ANON_KEY` | Publishable key |

**안 넣으면 목 데이터로 도는 앱이 나옵니다.** 친구한테 줄 빌드에는 반드시.
(Publishable key 는 빌드 결과물에 그대로 박혀 나갑니다. 원래 공개 전제인
키라 괜찮고, 막는 건 RLS 입니다. Secret key 는 절대 넣지 마세요)

### 2. 돌리기

**Actions 탭 → build → Run workflow.** `v0.1.0` 같은 태그를 푸시해도 돕니다.
끝나면 실행 화면 하단 Artifacts 에서 받습니다:

- `run-study-macos` — `.dmg` (인텔·애플실리콘 겸용 유니버설)
- `run-study-windows` — `-setup.exe` (설치 프로그램)

> 비공개 레포는 러너 분당 요금이 다르게 붙습니다. 윈도우 2배, **맥 10배.**
> 무료 한도(월 2000분) 기준 맥 빌드 10분이면 100분 차감이라 한 달에
> 스무 번쯤 돌릴 수 있습니다.

### 3. 친구가 열 때

**둘 다 서명이 없어서 경고가 뜹니다.** 악성이라는 뜻이 아니라 유료 개발자
등록을 안 했다는 뜻입니다.

| | 여는 법 |
|---|---|
| Windows | "Windows의 PC 보호" 창 → **추가 정보** → **실행** |
| macOS | 시스템 설정 → 개인정보 보호 및 보안 → **확인 없이 열기**<br>또는 `xattr -dr com.apple.quarantine "/Applications/run study.app"` |

경고까지 없애려면 코드 서명이 필요합니다 — Apple Developer $99/년,
Windows 코드 서명 인증서 연 $200~400.

### Windows 에서 다른 점

- **알림 끄기(집중 모드)가 없습니다.** Windows 집중 지원은 서드파티가 켤 수
  있는 공개 API가 없어서, 설정에서 항목 자체를 감췄습니다. 상태 표시로서의
  "집중 중"과 타이머는 그대로 동작합니다.
- 트레이 아이콘이 다릅니다. macOS 는 템플릿(알파만) 아이콘이라 흑백으로
  나오고, Windows 는 색이 들어간 `icons/tray-color.png` 를 씁니다.
- 팝오버가 트레이 아이콘 **위**로 붙습니다(작업 표시줄이 아래라서).
  판단은 OS 가 아니라 아이콘이 화면 위쪽 절반에 있는지로 하기 때문에,
  작업 표시줄을 위나 옆으로 옮겨둬도 알아서 맞춰집니다.
- WebView2 런타임이 필요한데 설치 프로그램이 자동으로 받아옵니다
  (Windows 10 최신 이상은 대개 이미 있음).

## 자동 업데이트

한 번 설치하면 **다음부터는 앱이 알아서 알려줍니다.** 새 버전이 있으면
팝오버 위에 띠가 뜨고, 누르면 받아서 설치하고 재시작까지 합니다.
친구가 GitHub 에 다시 들어올 일이 없습니다.

### 새 버전 내는 법

1. `package.json` 과 `src-tauri/tauri.conf.json` 의 `version` 을 올린다 (둘 다)
2. 푸시하고 Actions → build → Run workflow → 태그 `v0.3.0`
3. 끝. 켜져 있는 앱들이 알아서 잡는다

### 왜 레포가 공개여야 하나

앱이 릴리스 파일을 받으러 갈 때 로그인을 할 수 없습니다. 비공개면 404 만
받아서 업데이트가 영영 안 잡힙니다.

### 서명 키

업데이트 파일은 **서명이 확인돼야만 설치됩니다.** 아무나 가짜 업데이트를
밀어넣지 못하게 하는 장치입니다. 앱 실행 경고(SmartScreen·Gatekeeper)를
없애주는 코드 서명과는 **다른 키**이고, 이쪽은 무료입니다.

- 공개키: `src-tauri/tauri.conf.json` 의 `plugins.updater.pubkey`
- 비밀키: Actions Secret `TAURI_SIGNING_PRIVATE_KEY`

> ⚠️ **비밀키를 잃어버리면 이미 깔린 앱에 업데이트를 영영 못 보냅니다.**
> 새 키로 바꾸면 기존 사용자는 전부 다시 설치해야 합니다. 백업해 두세요.

다시 만들려면 `npm run tauri signer generate` — 단, 위 경고대로
기존 설치본과의 연결은 끊깁니다.

### 주의: 릴리스를 prerelease 로 내지 말 것

업데이터는 `releases/latest` 를 봅니다. GitHub 의 "latest" 는 미리보기
릴리스를 건너뛰기 때문에, prerelease 로 내면 업데이트가 안 잡힙니다.
워크플로에 `prerelease: false` 로 박아뒀습니다.

## 미니게임 (워들 · 숫자야구)

메뉴 막대 팝오버의 **🎮** 버튼을 누르면 별도 창이 열립니다.
팝오버(382×460)에는 보드와 키보드가 안 들어가고, 팝오버는 포커스를
잃으면 닫히기 때문에 게임 중에 판이 사라집니다. 그래서 창을 따로 띄웁니다.

### 같은 방이면 같은 문제

서버가 없어서 "랜덤"을 쓰면 사람마다 다른 문제를 풀게 됩니다.
그래서 정답은 **파티 ID + 날짜 + 게임 종류를 해시해서** 목록의 인덱스로
뽑습니다. 같은 방, 같은 날이면 누가 어디서 열어도 같은 답이 나옵니다.

정답은 **DB 에 저장하지 않습니다.** 저장하면 같은 파티원이 그 행을 읽을
수 있어서 오히려 더 쉽게 샙니다. 각자 자기 기기에서 계산합니다.
`game_progress` 에는 몇 번 만에 어떻게 풀었는지(채점 결과 패턴)만 올라가고,
**추측한 단어 자체는 안 넘어갑니다** — 그게 넘어가면 답이 새니까요.

> 개발자도구를 열면 정답을 볼 수는 있습니다. 친구끼리 하는 게임이라 그
> 선까지만 막았습니다. 서버 채점이 필요해지면 `submit_guess` RPC 로
> 옮기면 됩니다 (`create_party` 와 같은 SECURITY DEFINER 방식).

### 단어 목록

`src/lib/game/words.json` 에 두 개가 들어 있습니다.

| | 개수 | 쓰임 |
|---|---|---|
| `answers` | 1,703 | 오늘의 정답을 여기서 뽑음. 빈도 높은 흔한 단어만 |
| `allowed` | 12,653 | 입력을 받아줄지 판단. 사전에 있으면 다 통과 |

나눠야 하는 이유: 하나로 합치면 `SOUGH` 같은 게 정답으로 나오거나,
반대로 아는 단어인데 입력이 거부됩니다.

**실행 중에는 사전 API 를 부르지 않습니다.** 매 추측마다 왕복이 생겨
느리고, 인터넷이 끊기면 게임이 멈추기 때문입니다.

목록을 다시 만들려면:

```bash
pip install wordfreq
npm i an-array-of-english-words
python3 scripts/build-words.py
```

`ANSWER_MIN_ZIPF` 를 올리면 정답이 더 쉬워지고, 내리면 목록이 늘어납니다.

### 보드

빈 칸을 미리 다 깔지 않고 **제출할 때마다 줄이 하나씩 늘어납니다.**
남은 횟수는 보드 위에 숫자로 따로 보여줍니다.

### 채점 로직

`src/lib/game/rules.ts` 는 입출력이 없는 순수 함수만 있습니다.
`npm test` 로 13개 테스트가 돕니다 — 중복 글자 처리, 시드 결정성,
정답 분포까지 봅니다. 채점이 틀리면 아무것도 못 믿으니 여기는 꼭 돌리세요.

## 상태 우선순위 (`src/lib/status.ts`)

```
1. 수동 오프라인   ← 항상 이김. 앱을 껐다 켜도 유지
2. 집중 중         ← 수동으로 켰거나, 타이머가 돌거나
3. 온라인          ← 기본값
```

해제는 **"들어온 문으로 나간다"**:

- 타이머로 진입한 집중 중 → 타이머 종료 시 자동 해제
- 수동으로 켠 집중 중 → 수동으로만 해제
- 수동 오프라인 → 수동으로만 해제

## 알림 끄기 (macOS 집중 모드)

> Windows 에는 없는 기능입니다. Windows 집중 지원도 서드파티가 켤 수 있는
> 공개 API가 없어서, 설정에서 이 항목을 아예 숨깁니다.

macOS는 서드파티 앱이 집중 모드를 켜는 **공개 API를 제공하지 않습니다.**
다른 앱의 알림을 가로채거나 억제하는 것도 불가능합니다(Apple DTS 공식 답변).
그래서 유일하게 지원되는 경로인 **단축어**를 통해 우회합니다.

단축어 앱에서 두 개를 만들어 주세요:

| 단축어 이름 | 동작 |
|---|---|
| `run study 집중 켜기` | 집중 모드 설정 → 방해금지 켜기 |
| `run study 집중 끄기` | 집중 모드 설정 → 방해금지 끄기 |

이름 앞부분(`run study 집중`)은 설정에서 바꿀 수 있습니다.
앱은 `shortcuts run "<이름> 켜기"`를 실행합니다.

## Supabase 연결

`.env` 에 키가 없으면 **목 데이터**로 돌아가고, 있으면 진짜 백엔드에 붙습니다.
코드는 이미 양쪽 다 되어 있으니 아래 4단계만 하면 됩니다.

### 1. 프로젝트 만들고 익명 로그인 켜기

supabase.com 에서 프로젝트를 만든 뒤
**Authentication → Providers → Anonymous sign-ins** 를 켭니다. (기본은 꺼져 있음)

### 2. 스키마 올리기

**SQL Editor** 에 `supabase/schema.sql` 을 통째로 붙여넣고 실행합니다.
테이블 4개(`profile` · `party` · `party_member` · `reaction`), RLS 정책,
파티 생성·참여 함수가 한 번에 만들어집니다.

### 3. 키 넣기

```bash
cp .env.example .env
# Project Settings → API 에서 URL 과 anon key 복사
```

### 4. 끝

`npm run dev` 하면 자동으로 익명 로그인이 되고, 파티 만들기 화면이 뜹니다.
코드를 친구에게 보내면 그 코드로 들어옵니다.

### 연결이 됐는지 어떻게 아나

**목으로 조용히 떨어지지 않습니다.** 셋 중 하나가 화면에 나옵니다.

| 화면 | 뜻 |
|---|---|
| 하단에 **`목 데이터`** 배지 | 키가 없음 → 의도된 목 모드 |
| **⚠️ 연결하지 못했어요** | 키는 있는데 실패 — 메시지에 원인이 나옴 |
| 배지 없이 파티 화면 | 진짜로 붙음 |

키가 있는데 실패했을 때 목으로 떨어지면, 화면에는 6명이 멀쩡히 떠서
"되네?" 하고 넘어가게 됩니다. 그래서 그 경우는 일부러 에러를 냅니다.

### 로그인을 왜 안 만들었나

**익명 로그인도 진짜 `auth.uid()` 와 `authenticated` 역할을 받기 때문에
RLS 가 그대로 성립합니다.** 그래서 로그인 화면 없이도 남의 상태를 고치거나
남의 반응을 지우는 게 서버 차원에서 막힙니다.
(자체 UUID 를 쓰면 클라이언트가 자칭하는 값이라 RLS 가 성립하지 않습니다)

대신 익명 계정은 **기기에 묶입니다.** 앱 데이터를 지우거나 기기를 바꾸면
돌아올 수 없어요. 그래서 설정에 **"계정 연결"** 을 열어뒀습니다 —
`linkIdentity()` 로 GitHub 을 붙이면 영구 계정이 됩니다.

> ⚠️ 데스크톱 앱에서 OAuth 는 시스템 브라우저를 열고 커스텀 URL 스킴으로
> 돌아와야 합니다. 딥링크 설정 전까지는 `npm run dev`(브라우저)에서만 동작합니다.

### 무엇이 어디에 사는가

| | 저장 위치 | 이유 |
|---|---|---|
| 프로필, 상태 메시지, 반응 | **DB** | 남아야 함 |
| 온라인 여부, 집중 시작 시각 | **Realtime Presence** | 휘발성 |
| 내 설정, 수동 상태 | localStorage | 나만 보는 것 |

**⚠ 타이머는 절대 초 단위로 브로드캐스트하지 마세요.**
Supabase Presence 는 고빈도 업데이트용이 아니라고 공식 문서에 명시돼 있습니다.
`focus_started_at`(시작 시각) 하나만 보내고 흐르는 숫자는 각자 계산합니다.
이미 그렇게 짜여 있습니다.

상태 메시지를 바꾸면 `status_id` 가 새로 발급되고, 그 메시지에 달렸던
반응은 트리거가 정리합니다.

## 문제가 생겼을 때

- **화면에 빨간 제목과 함께 오류 내용이 뜬다** — 그 내용을 그대로 알려주면 됩니다.
  하얀 화면은 나오지 않게 해뒀습니다 (`src/main.tsx` 의 crash 화면)
- **버전은 설정 창 맨 아래**에 있습니다. 버그를 말할 때 이 번호를 같이 주세요
- **더 자세히 보려면** 창에서 우클릭 → 검사. 릴리스 빌드에서도 열립니다
  (`Cargo.toml` 의 `devtools` 기능)
